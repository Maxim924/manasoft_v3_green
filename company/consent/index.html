Конфиденциальность и персональные данные

Информация об обработке данных при использовании этой версии сайта.

Как работает форма

Форма на этом сайте формирует текст обращения в вашем браузере. Имя, контакт и описание задачи не отправляются на сервер, не сохраняются в cookie или localStorage. Копирование текста происходит только при нажатии соответствующей кнопки.

Отправка обращения

Если вы отправляете подготовленный текст по электронной почте, указанные сведения передаются компании через ваш почтовый сервис. Перед отправкой проверьте состав данных в письме.

Технические данные

При размещении сайта сервер может обрабатывать технические сведения запроса, необходимые для выдачи страниц. На сайте не подключены счётчики аналитики. В этой версии используются системные шрифты устройства без запросов к внешнему сервису шрифтов.
